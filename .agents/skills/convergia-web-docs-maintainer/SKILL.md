# Mantener documentación de Convergia Web

1. Leer `ai-docs/00-index.md` y `ai-docs/99-convenciones.md` completamente.
2. Verificar código, configuración o contrato ejecutado; no confiar en planes históricos.
3. Actualizar el nodo mínimo y mantener enlaces wiki bidireccionales.
4. Marcar explícitamente contenido implementado, planeado o incierto.
5. Mantener la documentación autosuficiente dentro del clon y no enlazar rutas hacia repos vecinos.
6. Excluir secretos, tokens, teléfonos, transcripciones y datos personales.
7. Validar que enlaces wiki y rutas resuelvan, y que el índice alcance cada nodo.
8. No desplegar, reiniciar servicios ni ejecutar acciones que originen llamadas.

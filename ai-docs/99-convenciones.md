# Convenciones

- Una nota por concepto; nombres estables `NN-kebab-case.md`.
- Usar enlaces wiki para el grafo y rutas literales para fuentes del mismo repositorio.
- Mantener cada nota idealmente bajo 120 líneas y sin copiar código extenso.
- Escribir hechos verificables; marcar deuda, propuesta o incertidumbre.
- Actualizar `updated` sólo si cambia el contenido.
- Actualizar el nodo mínimo cuando cambien arquitectura, integración, operación o roadmap.
- No depender de rutas que salgan del clon ni duplicar manuales de otro repositorio.
- No guardar secretos, tokens, teléfonos, transcripciones ni datos personales.
- Antes de editar, buscar con `rg`; después, comprobar enlaces, rutas y el índice.
